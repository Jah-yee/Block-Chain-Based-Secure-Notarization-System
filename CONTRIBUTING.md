# Contributing to BBSNS

First off, thank you for considering contributing to the Block-Chain Based Secure Notarization System (BBSNS).

## 🚀 Getting Started

1. **Fork the repository** on GitHub.
2. **Clone the project** to your local machine.
3. **Run `npm install`** at the root to install workspaces dependencies.
4. Set up your `.env` files based on the `.env.example` templates in the respective folders.

## 🛠️ Development Workflow

* Create a new branch for your feature: `git checkout -b feature-name`
* Write clean, documented code and include tests where applicable.
* Run `npm run lint` and ensure tests pass locally before committing.

## 📥 Submitting Changes

1. Push your branch to your fork on GitHub.
2. Open a **Pull Request** against the `main` branch.
3. Ensure your PR description clearly explains the changes and references any open issues.

## 🐛 Reporting Bugs

If you find a bug, please use the GitHub Issue Tracker. Include:
- Steps to reproduce
- Expected behavior vs. actual behavior
- Relevant logs or screenshots
